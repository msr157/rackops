# Rackops Context

## Current Status
- Server Management Platform UI / Backend
- **Infrastructure Context:** Deployed via Dokploy to a 3-node Docker Swarm (`mayank-mainframe-server`, `BetterRoad-VM`, `rackops-vm`).
- **Routing:** Cloudflare Tunnel (`cloudflared-main`) → Traefik → Swarm Service.
- **Registry:** Pushed to local registry (`127.0.0.1:5000`) before Swarm deployment.

## Architectural Decisions
- Removed public IP bindings; all incoming traffic MUST route via Cloudflare Tunnel.
- TLS is terminated at Cloudflare Edge. Internal endpoints use `http://`.
- Swarm state relies entirely on Netbird overlay network for quorum.
